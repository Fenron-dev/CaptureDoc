# Screenshots aufnehmen

| Modus | Bedienung |
|---|---|
| Bereich | ziehen; einfacher Klick nimmt das Fenster unter dem Mauszeiger (bzw. den Monitor) |
| Fenster | Fenster anklicken |
| Aktives Fenster | `Alt+Druck` |
| Monitor | Monitor unter dem Mauszeiger |
| Alle Bildschirme | `Strg+Druck` |
| Letzter Bereich | `Umschalt+Druck` |

Esc oder Rechtsklick bricht ab. Verzögerung und Cursor in der Leiste. Was nach der Aufnahme passiert: Einstellungen ⚙ → „Nach der Aufnahme“.
